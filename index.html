01 · OVERVIEW

Old software is often
old knowledge.

JASS Legacy Software Lab is a personal laboratory for preserving, exploring, testing and modernizing classic DOS and Windows business software. The goal is to understand the original system first, then build a careful path forward.

01

Preserve

Keep historically appropriate environments available so software and workflows can be studied in context.

02

Explore

Use virtual machines to examine applications, databases, development tools and file formats.

03

Understand

Learn how the original application and its data actually work before changing them.

04

Modernize

Create practical routes toward Python, SQL, SQLite, PostgreSQL and PySide6.

05 · JASS PHILOSOPHY

Don't rewrite blindly.
Understand first.

A legacy system can contain decades of domain knowledge. The practical approach is to preserve the original environment, understand the workflow and data, document what matters, and then modernize carefully.

PreserveKeep the original environment available.
DocumentMake hidden assumptions visible.
ExtractSeparate valuable data from obsolete dependencies.
ModernizeMove useful capabilities toward maintainable tools.
